實作說明

這個網頁用了哪些 jQuery 功能？

按鈕與選單使用 .on() 綁定事件；深色模式使用 .toggleClass()；筆記區使用 $.getJSON() 非同步取得資料，並以 .text() 建立文字內容。

資料載入失敗時會怎樣？

網頁會顯示失敗提示，保留重試按鈕。JSON 檔案與網頁位於同一個 GitHub Pages 網站，不需要 API 金鑰。
