LESSON 01

Git

工作目錄是正在編輯的檔案；暫存區挑選下一次提交的內容；commit 是版本快照。GitHub 是託管儲存庫的網站，與 Git 工具本身不同。

git status
git add index.html
git commit -m "Add personal page"

LESSON 02

HTML5

HTML 決定內容結構。h1 是主要標題，main 包住主要內容，nav 表示導覽；語意化標籤幫助瀏覽器與輔助工具理解頁面。

<main>
  <h1>謝宥祺的個人網頁</h1>
  <p>前端技術實作</p>
</main>

LESSON 03

CSS

CSS 負責顏色、間距與版面。class 選擇器用小數點開頭。Grid 可以排列卡片，media query 可依視窗寬度切換欄數。

.card { padding: 24px; }
.grid { display: grid; grid-template-columns: repeat(3, 1fr); }
@media (max-width: 700px) {
  .grid { grid-template-columns: 1fr; }
}

LESSON 04

JSON

JSON 是文字資料格式。物件用大括號，陣列用中括號；屬性名稱及字串必須使用雙引號，不能加入註解或尾端多餘逗號。

{"topic":"Ajax","count":6,"ready":true}

LESSON 05

Ajax

Ajax 讓網頁在背景向伺服器請求資料，再局部更新畫面，不必整頁重載。名稱雖包含 XML，實務上也常傳 JSON。非同步請求須處理成功、失敗與等待狀態。

$.getJSON('notes.json')
  .done(function(data) { console.log(data); })
  .fail(function() { console.log('載入失敗'); });

LESSON 06

jQuery

jQuery 是 JavaScript 函式庫。$() 選取元素，.on() 綁定事件，.text() 更新文字，.toggleClass() 切換樣式類別。先載入 jQuery，再載入依賴它的程式。

$('#theme').on('click', function () {
  $('body').toggleClass('dark');
});
